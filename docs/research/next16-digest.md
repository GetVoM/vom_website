# Next.js 16.4.3 conventions digest

Compiled on 2026-10-25 from the docs bundled with this project's installed version at `node_modules/next/dist/docs/01-app/`. Those docs are the authority; this digest is the short version for people and agents who last used Next.js 13 to 15. Re-check the bundled docs after any `next` upgrade.

Project context: App Router, `cacheComponents: true`, `partialPrefetching: true`, React 19.3, Tailwind v4, pnpm, TypeScript. Arabic (RTL) at `/`, English at `/en`. About 400 permanent redirects from WordPress, sitemaps, hreflang, canonicals, JSON-LD, OG images, top Core Web Vitals.

## 1. Breaking changes and renames in v16 (vs 13 to 15)

- Runtime floor: Node 20.9+, TypeScript 5.1+. Turbopack is the default for `next dev` and `next build`; `turbopack` is a top-level config key; `--webpack` opts out.
- Async request APIs, sync access removed: `cookies()`, `headers()`, `draftMode()`, and `params` / `searchParams` in `layout`, `page`, `route`, `default`, `opengraph-image`, `twitter-image`, `icon`, `apple-icon` are all Promises. Codemod: `npx @next/codemod@canary next-async-request-api .`
- Global type helpers, no import: `PageProps<'/blog/[slug]'>`, `LayoutProps<'/[lang]'>`, `RouteContext<'/api/x/[id]'>`. Generated by `next dev` / `next build` / `next typegen`.
- `opengraph-image.tsx` default export receives `{ params: Promise<…>, id: Promise<string> }`. `sitemap({ id })` receives `id: Promise<string>`.
- `middleware.ts` is replaced by `proxy.ts` with a named export `proxy` (or default). Node.js runtime only; a `runtime` export throws. `skipMiddlewareUrlNormalize` is now `skipProxyUrlNormalize`. Codemod: `npx @next/codemod@canary middleware-to-proxy .`
- `cacheComponents: true` replaces `experimental.ppr`, `experimental.dynamicIO`, `experimental.useCache`. With it enabled the route segment configs `dynamic`, `dynamicParams`, `revalidate`, `fetchCache` are removed and `runtime` must be deleted. New segment exports: `ensureStatic` (16.4), `instant` (16.3), `prefetch`.
- Caching APIs: `cacheLife` / `cacheTag` are stable (drop `unstable_`). `revalidateTag(tag, profile)` requires a second argument (`'max'` recommended). New `updateTag(tag)` (Server Actions only) and `refresh()` from `next/cache`. `unstable_rootParams` is removed; use `next/root-params`.
- `next/image`: `priority` is deprecated in favour of `preload`; `images.domains` is deprecated in favour of `remotePatterns`; `qualities` defaults to `[75]` (other values 400); `minimumCacheTTL` default 4h; local `src` with a query string needs `images.localPatterns[].search`.
- Removed: AMP, `next lint` and the `eslint` config key (build no longer lints), `serverRuntimeConfig` / `publicRuntimeConfig`, build-output size columns.
- Other: parallel-route slots need `default.js`; Next no longer overrides `scroll-behavior: smooth` (add `data-scroll-behavior="smooth"` on `<html>` to restore); `reactCompiler` and `typedRoutes` are stable top-level keys; with Cache Components the router keeps recent routes mounted via `<Activity mode="hidden">`, so state persists on back navigation and effects re-run.
- Still flagged: `metadata.themeColor` / `colorScheme` / `viewport` belong in `export const viewport: Viewport`; `onLoadingComplete` is now `onLoad`.

## 2. Rendering and caching model

Default: every async I/O is dynamic; nothing is cached unless you say so. The build prerenders a static shell (HTML plus RSC payload) per route; anything uncached must sit behind `<Suspense>` or the build raises blocking-prerender errors. Static work (module imports, sync fs, pure computation) prerenders automatically.

`'use cache'` (function, component, or file level; must be `async`): return value cached. Cache key = build id (or `deploymentId`) + function id + serialized args + captured closure variables + any `next/root-params` getters actually read. Args must be RSC-serializable. Cannot call `cookies()` / `headers()` / `searchParams` inside (pass values in). The runtime cache is an in-memory LRU per instance; `'use cache: remote'` for a shared handler; `'use cache: private'` for request-bound data. All entries die on a new deploy.

`cacheLife(profile | { stale, revalidate, expire })`: call it in every cache scope. Presets: `default` 5m/15m/never, `seconds`, `minutes`, `hours`, `days`, `weeks`, `max` 5m/30d/1y. Custom profiles go in `next.config.ts` under `cacheLife`. `revalidate: 0` or `expire < 5min` makes a dynamic hole; `stale < 30s` excludes from prerender.

`cacheTag(...tags)` plus `revalidateTag(tag, 'max')` (Server Function or Route Handler) or `updateTag(tag)` (Server Action only, immediate).

`ensureStatic` (`'auto' | 'shell' | 'prefetch' | 'navigation' | false`, page or layout export): `'navigation'` requires the complete route to be prerenderable and is validated in dev and build; dynamic routes must export `generateStaticParams` returning at least one complete param set. Set it on a layout to cover everything beneath. `instant` is dev-only validation that navigation paints immediately.

Partial prefetching: `<Link>` prefetches one shared App Shell per route. Content keyed by URL data cannot live in the App Shell; await `params` inside `<Suspense>`, not at the top of a layout.

Dynamic routes: `generateStaticParams` must return at least one param (empty array is a build error). Listed params are fully prerendered; unlisted ones get the shell then upgrade. `dynamicParams` is gone; call `notFound()` for unknown slugs.

Recommended pattern for this site: static marketing pages with zero request-time reads; blog and sector data behind `'use cache'` + `cacheLife('max')` + `cacheTag('posts', \`post-${slug}\`)`; a CMS webhook Route Handler calling `revalidateTag('posts', 'max')`; `generateStaticParams` listing every slug per locale; `export const ensureStatic = 'navigation'` on the marketing and blog layouts; calculators as `'use client'` leaf components reading URL state with `useSearchParams`; downloadable templates in `public/` or a Route Handler.

Accidental dynamism: `await params` at the top of a layout; server `searchParams`; `cookies()` / `headers()`; `Date.now()`, `new Date()`, `Math.random()` during render; uncached `fetch` or ORM reads; `connection()`; nonce-based CSP; `generateMetadata` doing an uncached fetch; `cacheLife('seconds')`.

Bots: HTML-limited bots skip the static shell and render dynamically so metadata lands in `<head>`; data the shell needed at build time must also be reachable at request time.

## 3. Routing for i18n

The docs recommend nesting everything under `app/[lang]/` with the root layout at `app/[lang]/layout.tsx`, `generateStaticParams` on that layout returning `[{ lang: 'ar' }, { lang: 'en' }]` (required under cacheComponents), and `next/root-params` (`import { lang } from 'next/root-params'; await lang()`) callable from any Server Component or server utility (not Client Components, Server Actions, Route Handlers). Segment names must be valid JS identifiers. Dictionaries: `import 'server-only'` plus lazy JSON `import()`; narrow with `hasLocale()` and `notFound()`.

Arabic at `/` and English at `/en` with no auto-redirect (inferred from documented primitives; the guide only shows the redirect variant): keep `app/[lang]` and add a `rewrites()` `beforeFiles` rule in `next.config.ts` mapping `/` to `/ar` and `/:path((?!en(?:/|$)|api|_next|.*\\..*).*)` to `/ar/:path`, leaving `/en/...` to match the filesystem. Add a permanent redirect `/ar/:path*` to `/:path*` so the prefixed Arabic URL is never indexable. Generate all internal hrefs as `/…` (ar) or `/en/…`. `experimental.globalNotFound: true` plus `app/global-not-found.tsx` is the documented answer for 404s when the root layout sits under a dynamic segment.

## 4. Metadata and SEO APIs

- `export const metadata: Metadata` or `export async function generateMetadata(props, parent)`; Server Components only; shallow merge per segment (a child's `openGraph` replaces the parent's whole object). `title: { default, template: '%s | VoM' }`.
- `metadataBase: new URL('https://getvom.com')` in the root layout; relative URLs without it are a build error. `alternates: { canonical, languages: { ar, en, 'x-default' } }` emits canonical and hreflang. `robots`, `openGraph` (`locale: 'ar_SA'`, `type: 'website' | 'article'`, `publishedTime`, `authors`, `images`), `twitter`, `verification`, `pagination`. Viewport and theme-color go in `export const viewport`.
- Under cacheComponents `generateMetadata` follows the same rules as components: `'use cache'` it (return strings, not `URL` objects), rely on a cached data helper, or add a Suspense-wrapped `connection()` marker. `fetch` is memoized across `generateMetadata` and the page; use `React.cache` for other reads.
- File conventions: `app/favicon.ico`, `icon.*`, `apple-icon.*`, `opengraph-image.*` plus `opengraph-image.alt.txt`, `twitter-image.*`. Generated: `opengraph-image.tsx` with `export const alt`, `size = { width: 1200, height: 630 }`, `contentType`, default export returning `new ImageResponse(jsx, { ...size, fonts })` from `next/og`; satori supports a flexbox subset only; load font files with `readFile` at module scope. An Arabic TTF must be passed in `fonts` for Arabic OG text.
- Sitemaps: `app/sitemap.ts` returning `MetadataRoute.Sitemap` with `alternates.languages` per entry (emits `xhtml:link hreflang`). Split via nested `app/blog/sitemap.ts` or `generateSitemaps()` + `sitemap({ id })`, served at `/blog/sitemap/0.xml`; list each in `robots.sitemap` (no automatic index file).
- `app/robots.ts` returns `MetadataRoute.Robots`. `app/manifest.ts` returns `MetadataRoute.Manifest`.
- JSON-LD: native `<script type="application/ld+json" dangerouslySetInnerHTML={{ __html: JSON.stringify(jsonLd).replace(/</g, '\\u003c') }} />` in the page (not `next/script`); type with `schema-dts`.
- 404 status: `notFound()` before streaming gives a real 404; after streaming it gives 200 plus an injected noindex. For hard 404s on bad slugs, check the slug early.

## 5. Redirects at scale

- `redirects()` in `next.config.ts`: `{ source, destination, permanent }` gives 308 / 307; use `statusCode: 301` instead of `permanent` for a literal 301. path-to-regexp sources, `has` / `missing` conditions; applied before the filesystem and before proxy; locales only as hardcoded prefixes. Platforms cap the list (Vercel 1,024); about 400 fits comfortably.
- Trailing slash: default redirects `/x/` to `/x` (308) before your rule; `trailingSlash: true` flips globally.
- Proxy-based maps for very large lists (`NextResponse.redirect(dest, 308)` from a JSON map) with a `matcher` excluding `_next/static|_next/image|favicon.ico|sitemap.xml|robots.txt`.
- `permanentRedirect(path)` from `next/navigation`: 308 in Server Components and Route Handlers; call outside `try`.
- Resolution order: `headers` → `redirects` → proxy → `beforeFiles` rewrites → filesystem → `afterFiles` → dynamic routes → `fallback` rewrites.

## 6. Images, fonts, scripts

- `next/image`: static import (auto width, height, blurDataURL) or `public/` path; remote needs `images.remotePatterns`; `width` + `height` required unless static import or `fill`; `sizes` whenever responsive; `preload` for the single LCP hero only; `placeholder="blur"`; `quality` must be in `images.qualities`; `formats: ['image/avif', 'image/webp']` optional; raise `minimumCacheTTL` for CMS images; SVG is auto-unoptimized; `sharp` required when self-hosting.
- `next/font`: `subsets: ['arabic', 'latin']`, variable fonts need no `weight`, `display: 'swap'` default, `variable: '--font-sans'` on `<html>`, Tailwind v4: `@theme inline { --font-sans: var(--font-sans); }`. `next/font/local` takes `src` entries `{ path, weight, style }`. Define fonts once in a `fonts.ts`.
- `next/script`: `beforeInteractive` (root layout only), `afterInteractive` default (GTM, analytics), `lazyOnload` (chat widgets). `@next/third-parties/google` exposes `GoogleTagManager`. `instrumentation-client.ts` at the project root runs before app code for analytics init.
- `useReportWebVitals` from `next/web-vitals` in a `'use client'` component mounted in the root layout; metric `{ id, name, value, rating, delta, navigationType }`; ship via `navigator.sendBeacon`.

## 7. MDX

`pnpm add @next/mdx @mdx-js/loader @mdx-js/react @types/mdx`. Config: `createMDX({ extension: /\.(md|mdx)$/, options: { remarkPlugins: ['remark-gfm'], rehypePlugins: ['rehype-slug'] } })`, `pageExtensions` including `md` and `mdx`, `export default withMDX(nextConfig)`. With Turbopack, plugins must be strings or `[name, serializableOptions]`. `mdx-components.tsx` at the project root is required: `export function useMDXComponents(): MDXComponents`. Blog pattern: `await import(\`@/content/${slug}.mdx\`)` plus `generateStaticParams`; use `notFound()` for unknown slugs. Frontmatter parsing is not provided by `@next/mdx`. `experimental.mdxRs` is not recommended for production.

## 8. Config worth enabling

- `typedRoutes: true`; `reactCompiler: true` (add `babel-plugin-react-compiler`); `images` (`remotePatterns`, `formats`, `qualities`, `minimumCacheTTL`); `cacheLife` custom profiles; `deploymentId`.
- `headers()` security set: HSTS, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`; CSP via `frame-ancestors`. Nonce CSP forces dynamic rendering and is incompatible with PPR, so use a static CSP in `headers()` or `experimental.sri`.
- `agentRules` (default true): `next dev` writes the managed block in `AGENTS.md` pointing at bundled docs. `experimental.agentFeedback` is off by default.
- `experimental.globalNotFound: true`, `trailingSlash`, `pageExtensions` for MDX, `output: 'standalone'` for Docker, `data-scroll-behavior="smooth"` on `<html>` if wanted.

## 9. Production checklist and deployment

Checklist: layouts plus `<Link>`; `error.tsx`, `global-error.tsx`, `global-not-found`; `'use client'` at leaves; request-time APIs inside `<Suspense>`; `public/` for static assets; `next/font`, `next/image`, `next/script`; Metadata API plus OG images, sitemap, robots; `NEXT_PUBLIC_` discipline; CSP; validate with `next build` then `next start`, Lighthouse, field data from `useReportWebVitals`; `@next/bundle-analyzer` since build output no longer prints sizes.

Deployment: Node.js server and Docker support every feature; static export does not (no `use cache`, no proxy, no PPR). Vercel gives the PPR shell at the edge and sub-second revalidation propagation; self-hosted Node serves the shell from origin and multi-instance setups need shared cache handlers. On-demand revalidation does not purge a third-party CDN.

## 10. Gotchas when coding from 14/15 memory

1. `dynamic`, `revalidate`, `dynamicParams`, `fetchCache`, `runtime = 'edge'` are removed under `cacheComponents`; use `use cache` + `cacheLife`, `ensureStatic`, `notFound()`.
2. `fetch` is not cached by default; wrap reads in `'use cache'` + `cacheLife()`.
3. `revalidateTag('posts')` is a type error; write `revalidateTag('posts', 'max')`.
4. `await params` at the top of a layout ties the shell to a URL; use `await lang()` from `next/root-params`.
5. `generateStaticParams` returning `[]` is a build error.
6. `middleware.ts` is deprecated; `proxy.ts` is Node-only.
7. `priority` on `<Image>` is now `preload`; `images.domains` is now `remotePatterns`; `quality={90}` silently coerces unless listed in `images.qualities`.
8. `metadataBase` is mandatory for relative canonical, OG and hreflang URLs; nested metadata objects replace rather than deep-merge.
9. `'use cache'` functions cannot return `URL` or class instances.
10. `cookies()` / `headers()` inside `'use cache'` may pass `next build` and fail under `next start`.
11. `sitemap({ id })` and `opengraph-image({ params, id })` receive Promises.
12. Nonce-based CSP forces every page dynamic.
13. `loading.tsx` is only a Suspense boundary.
14. `Date.now()` / `new Date()` during render blocks prerendering.
15. HTML-limited bots re-render the whole page dynamically.
16. `notFound()` after streaming starts returns 200 plus noindex.
17. `next lint` is gone; run ESLint yourself in CI.
18. Turbopack is the build default: MDX plugins by string; custom `webpack` config fails unless `--webpack`.
19. `<Link prefetch={true}>` resolves cached URL-specific content only.
20. Root-param segment names must be identifiers; `next/root-params` is unavailable in Route Handlers (sitemaps, OG images).
21. `images.localPatterns` is needed for local images with query strings.
22. Routes stay mounted via `<Activity>` on back-navigation: dropdown and dialog state persists and effects re-run.
