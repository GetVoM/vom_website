# Terms and conditions: text changes from the WordPress pages

The new page at `/terms-and-conditions/` and `/en/terms-and-conditions/` reproduces the WordPress terms (last saved there on 2026-09-14). The owner asked for **typo fixes only** on 2026-11-09: no rewording, no grammar changes, and each language keeps its own structure. This file lists every change so the text can be checked against the original before launch.

Source modules: `lib/content/legal/terms-ar.ts`, `lib/content/legal/terms-en.ts`. Clause numbers are the new page's anchors (`#clause-2-8` is clause 2.8).

## Left unchanged, for the owner to decide

- **Introduction is cut off in both languages.** "تمثل هذه الشروط والأحكام “عقدا” رسميا بين شركة المحاسبية السحابية" and "…a formal “Agreement” between the cloud accounting company." name only one party. The missing wording needs the company's legal name and the subscriber.
- **Arabic 8.35 list: "خدمات المرافق"** stands where the English has "Escort services". As written it reads as *utility services*, which changes the meaning of the prohibited list.
- **Arabic has no "Access and Data Export" heading**: its four clauses sit at the start of البيانات (4.1–4.3, the first two English clauses merged into 4.1). Kept as is (owner, 2026-11-09), so Arabic and English clause numbers differ from section 4 on.
- **Grammar** left as written (for example متاحًا in 4.1, قادر in the About paragraph, دون 16 عام in 8.24), as were the brand spellings فوم, ڤوم and ڤومـ, and the Eastern Arabic digits in ١٥٪ (5.4).
